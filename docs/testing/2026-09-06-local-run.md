# Local run, 2026-09-06

Manual checklist run on a real laptop against the real `~/.decadra`, `~/.claude`, and `~/.codex`. Driven by a local Claude Code session through its shell, with the home screen, the interactive baseline prompt, and the Codex TUI driven through a pseudo terminal. Timings are from `now --timing`.

Environment: macOS 24.5, Node 26.0.0, ccusage 20.0.20, Claude Code 2.1.x, Codex CLI 0.144.6, git 2.39.5, branch `claude/decadra-cli-plan-b290yv` at 9b1ab82 before this run. `npm run check` was green before and after the run.

Side effects of the run: four `assess` invocations appended 20 rows to `~/.decadra/verdicts.jsonl`. Starting Codex in this repository made Codex write `trust_level = "trusted"` for the repository into `~/.codex/config.toml` and two new rollouts under `~/.codex/sessions/2026/09/05/`. Decadra itself wrote nothing under `~/.claude` or `~/.codex`. The interactive baseline record went to a scratch `DECADRA_HOME`, not the real one.

## Passes

- `doctor` on a fresh `DECADRA_HOME`: every provider listed, no crash, pricing rows present. Exit 1 because the default `plans.json` prices no model, which is the documented first-run state.
- `doctor` on the real home: `no failures`, exit 0; `claude-fable-5-1` was already in `modelPricing`.

- Inside Claude Code, `!node dist/cli.js now`: one block, exact session match (id verified against `CLAUDE_CODE_SESSION_ID` in `--json`), cost and minutes present, exit 0, 560 ms.
- Home screen on a pseudo terminal at 120 columns: animates; `q`, `6`, Enter, space, Escape, and five down arrows then Enter all exit; the alternate screen and cursor are restored each time.
- Home screen at 80 columns: the logomark drops and the menu stays readable.
- `node dist/cli.js | cat` with the agent variables unset: help, no escape codes, no animation. Inside Claude Code the same pipe prints the `now` block because agent detection wins, which matches `commands.md`.
- `assess --months 3`: 2026-07 labelled `29/31 days`, 2026-09 labelled partial and excluded from evidence, recommendation names only that provider's plans, verdicts appended.
- `sessions --months 1`: 2 Claude sessions out of 10 files read; the 8 others have July and August content and were excluded by last activity rather than file mtime, which is correct. Medians match memory; the weak-proxy caveat is present.
- `--json` for `now`, `assess`, and `sessions` all parse in `jq`.
- `alerts check`: nothing printed, exit 0. `alerts schedule --weekly` without `--print`: one line error, exit 1.
- `npm run check` after adding the Codex fixture: 101 tests, no todo.
