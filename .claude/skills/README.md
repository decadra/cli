# Skills

Skills are repeatable procedures for this repository. Each lives in its own directory with a `SKILL.md` whose frontmatter has `name` and `description`, followed by the steps.

- `add-provider`: the step list from `docs/adding-a-provider.md` in executable form.
- `redact-fixture`: turns a real transcript or export into a fixture safe to check in.

Skills say what to do. `AGENTS.md` says what never to do. Both apply.
